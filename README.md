### Full Stack Developer Portfolio Site

Welcome to the **Naga Muruga Portfolio**—a stunning, modern, and fully responsive personal portfolio website showcasing the skills, projects, and achievements of Naga Muruga, a passionate Full Stack Web Developer specializing in Angular, Node.js, and PostgreSQL.

## About

This portfolio highlights the professional journey and expertise of Naga Muruga (aka *Nakks*) with 3.6+ years of industry experience. It emphasizes a blend of creativity and cutting-edge technology used to solve real-world problems through impactful digital solutions. The site features a clean, interactive UI/UX with smooth page transitions, a dark/light theme toggle, and accessibility across devices.

***

## Features

- **Single Page Application:** Seamless navigation between sections including Home, About, Portfolio, Academic Achievements, and Contact.
- **Dynamic Section Transitions:** Smooth animation between content sections with active state controls.
- **Light/Dark Mode Toggle:** User-controlled theme switching for optimal viewing experience.
- **Interactive Contact Form:** Send emails directly via EmailJS integration with client-side validation.
- **Professional Showcase:** Detailed timeline of work experience and education, skills with proficiency bars, and academic awards.
- **Portfolio Highlights:** Multiple projects demonstrated with images, tech stacks, and GitHub links.
- **Responsive Design:** Mobile-friendly layout with clean typography and visual hierarchy.
- **Social Links:** Direct links to LinkedIn, GitHub, Pinterest, ResearchGate, and Shopify profiles.

***

## Technologies Used

- **Frontend:** HTML5, CSS3 (with CSS variables for theming), JavaScript ES6, Angular (projects)
- **Backend:** Node.js (projects)
- **Tools & Libraries:** EmailJS for email functionality, Font Awesome for icons, Google Fonts (Poppins)
- **CMS:** WordPress (for some projects showcased)
- **Design:** Custom CSS animations, grid and flexbox layouts

## Getting Started

### Installation

1. Clone the repository  
   ```
   git clone https://github.com/nakks-007/portfolio.git
   ```
2. Open `index.html` in your preferred browser.

### Usage

- Navigate through different sections using the side control buttons.
- Toggle between light and dark theme using the moon icon button on the top right.
- Use the contact form to send a message directly — required fields are validated before sending.
- Explore project links directly to GitHub or deployed WordPress sites.
